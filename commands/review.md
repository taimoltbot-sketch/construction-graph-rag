# /review - 代碼審查

## 使用方式

```
/review [PR 連結 或 檔案路徑]
```

## 功能

1. 分析變更
2. 檢查品質
3. 安全性掃描
4. 提供建議

## 審查項目

### 程式碼品質
- [ ] 命名規範
- [ ] 函數長度
- [ ] 重複代碼
- [ ] 註解品質

### 安全性
- [ ] 敏感資訊暴露
- [ ] 輸入驗證
- [ ] SQL Injection
- [ ] 認證/授權

### 測試
- [ ] 測試覆蓋率
- [ ] 測試品質
- [ ] 邊界情況

## 輸出格式

```markdown
## Code Review

### 變更摘要
- 新增 3 個檔案
- 修改 1 個檔案

### ✅ 優點
- 命名清晰
- 單元測試完整

### ⚠️ 建議修改
- `src/api/main.py:45` - 缺少錯誤處理
- `src/etl/pipeline.py:78` - 可考慮快取

### ❌ 阻擋
- 發現 API Key 硬編碼！
```
