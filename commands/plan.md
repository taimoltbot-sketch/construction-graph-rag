# /plan - 專案規劃

## 使用方式

```
/plan <任務描述>
```

## 功能

1. 分析需求
2. 拆解任務
3. 識別依賴
4. 估算工時
5. 輸出里程碑

## 範例

```
/plan 建立 ETL Pipeline 將 PostgreSQL 資料轉換到 Neo4j
```

## 輸出

```markdown
## 任務拆解：ETL Pipeline

### Step 1: 資料提取
- [ ] 連接 PostgreSQL
- [ ] 設計 Schema 映射
- 預估：2 小時

### Step 2: 資料轉換
- [ ] 轉換為三元組
- [ ] 資料清洗
- 預估：3 小時

### Step 3: 資料載入
- [ ] Neo4j 連接
- [ ] 批次寫入
- [ ] 建立索引
- 預估：2 小時

## 總工時：7 小時
## 優先級：P0
```
